Settings — saving to GitHub

No token is stored in this site’s code or in any file in the repo. If you paste a token here, it is stored only in this browser’s localStorage, and it is sent only to api.github.com when saving.

Token: Not set — read-only mode

How to make a token

On GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Give it access to only the repo jkakarlapudi/workout-check-log, with Contents: Read and write. No other permissions. Set a short expiry. Paste it here on each phone that needs to save — Ram and Jay each paste the token on their own phone. Never share a screenshot of the token.
